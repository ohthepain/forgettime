Full experiment state and limitations
Fixed frontend: trailing Hann; power normalized by squared window sum; Slaney mel scale and area normalization; log1p(power / 1e-8); lag 1; selectable frequency-neighbor maximum filter on the previous log-mel frame. Optional rearming requires a later flux frame below its adaptive threshold before another accepted attack. These are exploratory heuristics, not validated ring suppression. Adaptive threshold uses only past 100 ms, mean + k standard deviations plus 0.005 floor; threshold history must fill before detection. Refractory 18 ms. Frame-center timestamp estimate only; retrospective localization remains undecided. Confirmation requires a strict local maximum over the selected future hops. No zero prehistory or padded tail. Single in-memory pass, not native/device performance evidence. File decoding uses browser mono channel averaging. UI execution is a prototype and may pause briefly on long files.
