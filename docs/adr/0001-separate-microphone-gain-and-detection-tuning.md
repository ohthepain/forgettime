# Separate microphone gain from diagnostic detection tuning

Microphone Input gain changes incoming PCM before both detection and retention; imported audio is preserved. Import/replay Detection sensitivity is a diagnostic adjustment of the shared detector, isolated from live defaults so a setting that fixes one passage cannot silently change live behavior. Reported passages and settings inform deliberate algorithm improvements checked against regressions, rather than automatic adaptation; Detection sensitivity and Detection balance leave internal detector parameters free to evolve. The additional balance control was requested for recorded-material experiments: it blends energy and frequency-change attack evidence before a single decision, defaults to frequency change, and remains isolated from live capture.
